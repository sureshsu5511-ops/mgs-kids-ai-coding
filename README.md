## Deploy with GitHub Pages

1. Create a new GitHub repository.
2. Upload all files and folders from this repository.
3. Commit the files to the `main` branch.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **GitHub Actions**.
6. The included workflow will publish the website.
7. Your GitHub Pages URL will be shown in the Pages settings.

## Important: application notifications

The front-end form is included in the website, but sending email/SMS automatically requires a form/backend service.

The repository does **not** contain passwords, API keys, SMTP credentials, or SMS gateway secrets. Add those securely through the chosen service or GitHub Actions secrets when connecting a backend.

## Custom domain

After GitHub Pages is working, a custom domain can be connected from:

**GitHub → Repository → Settings → Pages → Custom domain**
